# Dashboard

Este archivo es un placeholder temporal. El dashboard real (`.lvdash.json`) no se construye a
mano: se crea directamente en la UI de Databricks (o con el asistente de IA que sugiere gráficos
a partir de los datasets) sobre las tablas `gold.*`, y luego se guarda aquí mismo mediante
**"Commit to Git"** desde el propio dashboard, para quedar versionado ya validado por Databricks.

Ver `README.md` (raíz del repo) para la tabla de los 4 datasets/consultas y el tipo de
visualización de cada uno.

Una vez hecho el primer "Commit to Git", este archivo se reemplaza por el `.lvdash.json` real.
